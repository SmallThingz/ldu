LDU 0.1.1 fixes deletion errors, mouse controls, and idle CPU use, and adds file previews and fuzzy filtering.

- Deletion continues past individual failures and retries permission errors with the process's existing privileges. Remaining errors appear after each target finishes, in one scrollable report with full paths. Reports wait their turn while another dialog is open.
- Large selections and error reports no longer require processing the whole list on the input thread. Scanning pauses during active deletion, and successful removals update totals without a full rescan.
- Settled scans stop redrawing. Size cleanup now finishes instead of leaving “Updating sizes” on screen.
- The mouse wheel scrolls the list. Click a directory to open it; in visual mode, click or drag to select, and Ctrl-click or Ctrl-drag to deselect. The two-cell back arrow opens the parent directory. Long header paths show their final components.
- Press `/` to filter names in the current directory. Plain arrow keys move the visual-mode cursor; Shift-arrow keys extend selection.
- Wide terminals show directory and text previews. Symlinks show their destination path without opening it. Installed utilities can list archive entries or show PDF text; unavailable helpers fall back to file details. Preview helpers stop when LDU exits.
- Quitting with confirmed deletions lets them finish. A second Ctrl-C cancels the remaining work and exits.

Downloads cover Linux x86-64, ARM64, ARMv7 hard-float and RISC-V 64; macOS Intel and Apple Silicon; and Windows x86-64 and ARM64. Builds use speed optimization, thin LTO, one codegen unit and stripped symbols, with portable CPU settings.

Linux x86-64 and ARM64 offer both glibc and static musl downloads. ARMv7 uses static musl; RISC-V uses glibc. The glibc builds are tested with Ubuntu 24.04's glibc 2.39. Each archive includes the executable, license, usage notes and dependency license notices. `SHA256SUMS` contains the archive checksums.

Deletion requires Linux and accessible procfs. Archive and PDF previews require a suitable installed utility on Linux or macOS. Windows previews show file details; allocated size is approximated by apparent size, and hard links are not deduplicated.
